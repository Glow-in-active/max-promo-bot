# Promo

Бот десятидневной промоакции на Go и PostgreSQL: промокоды, подписка на партнёров, дневные шансы, розыгрыши и получение призов.

## Запуск

Нужны Docker Compose с поддержкой `--wait` и make. Go и аккаунт MAX для demo не требуются.

```sh
make up
curl --fail http://127.0.0.1:8080/readyz
```

[Описание проекта](docs/index.md) · [API и Postman](docs/api.md)

Настройки по умолчанию работают без `.env`. Порты доступны только локально. `make logs` показывает логи, `make down` останавливает стенд с сохранением данных.

## Проверка

Для проверки в браузере запустите отдельный стенд:

```sh
make simulator
```

Откройте [127.0.0.1:4010](http://127.0.0.1:4010/), создайте сценарий и нажмите «Начать». В чате видны баннер и кнопки, работают ввод имени и согласие на получение приза. Рядом можно выбрать пользователя, задать подписку и подтвердить розыгрыш. У стенда своя PostgreSQL; аккаунт и токен MAX не нужны. Остановка: `make simulator-down`.

Импортируйте [коллекцию Postman](postman/promo.postman_collection.json) и [окружение](postman/local.postman_environment.json). Выберите окружение и запустите Collection Runner с начала. Коллекция сама создаёт данные и проверяет выдачу кодов, регистрацию, розыгрыши, согласие и резерв.

```sh
make integration   # Все интеграционные тесты и E2E с PostgreSQL
make e2e           # Только сквозной HTTP-сценарий бота
make mutate        # Доменные мутации
make smoke         # Контейнер, миграции, HTTP и завершение по SIGTERM
make simulator-check # Сквозная проверка стенда с внешним эмулятором
```

[Полный прогон и мутации с PostgreSQL](docs/testing.md) · [Устройство сервиса](docs/architecture.md) · [OpenAPI](api/openapi.yaml)

GitHub Actions проверяет PR в `main` и `dev`, а также push в эти ветки. Итоговый статус `CI` объединяет Go-тесты, PostgreSQL/E2E, мутации, Docker, Postman, симулятор и сборку документации. Логи доступны в артефактах запуска.

Все инструкции доступны как Markdown прямо в репозитории. Для локального сайта документации можно отдельно выполнить `make docs` и открыть [127.0.0.1:8000](http://127.0.0.1:8000/).

## Подключение MAX

В demo подписку и отправку сообщений заменяет адаптер; данные сохраняются в PostgreSQL. Для подключения нужны токен бота, права в каналах и публичный HTTPS webhook. [Настройка](docs/operations.md).
